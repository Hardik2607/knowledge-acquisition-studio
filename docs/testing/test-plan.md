# Test Plan

## Required gates
- Input validation
- Agent contract validation
- Artifact existence
- Output schema validation
- Error handling
- Retry behavior
- End-to-end execution
- Reproducibility

## Definition of done
A task is complete only when its acceptance criteria have passed and evidence is recorded.

## Acceptance criteria
Behavioural gates are defined in `acceptance-criteria.md` (AC-01…AC-23), with Given/When/Then form,
evidence shape and the phase-gate table. This plan covers the *mechanism*; the criteria cover the *assertions*.
