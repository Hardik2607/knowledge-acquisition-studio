# Create a Video with Voiceover Using AI Tools

1. Select a style for the video, such as 'flat vector science', to match the topic. [[k-12ce5143844b]]
2. Enable the 'with voiceover' option and input the topic of the video. [[k-f5f43e91d2db]]
3. Copy the transcript from the transcription tool and paste it into the video creation tool. [[k-8290bcaeecea]]
4. Disable the storyboard option if not needed and copy the prompt for the video. [[k-17094428e822]]
5. Load the voiceover by clicking the 'load voiceover' option or dragging the file into the video creation tool. [[k-194ff04ce73b]]
