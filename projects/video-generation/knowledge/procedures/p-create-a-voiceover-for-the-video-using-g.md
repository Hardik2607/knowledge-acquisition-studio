# Create a Voiceover for the Video Using Gemini 3.8 Flash TTS

1. Select the Gemini 3.8 Flash TTS model in Google AI Studio. [[k-cc48c1a20477]]
2. Go to the audio section and choose Gemini 3.8 Flash TTS. [[k-cc48c1a20477]]
3. Create new dialogue and select a voice from the variety available. [[k-5df7ef92b5e9]] [[k-11f906dfbf70]]
4. Paste the script into the dialogue box for text-to-speech conversion. [[k-11f906dfbf70]]
5. Customize the text-to-speech with options for style and tags for adding breaths, laughs, and other sounds. [[k-fccc49b4ad81]]
